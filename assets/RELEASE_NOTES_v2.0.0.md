## ⚡ 1-Liner Quick Install (Установка одной командой)

### 🐧 Linux / macOS Terminal
```bash
curl -fsSL https://raw.githubusercontent.com/SGBR22/antigravity-team/main/install.sh | bash
```
*Or via wget:*
```bash
wget -qO- https://raw.githubusercontent.com/SGBR22/antigravity-team/main/install.sh | bash
```

### 🪟 Windows PowerShell
```powershell
irm https://raw.githubusercontent.com/SGBR22/antigravity-team/main/install.ps1 | iex
```

## 🌐 English Release Overview

### 🌟 What's New in v2.0.0

1. **Full Linux & macOS Terminal Parity**:
   - Native `install.sh` remote curl/wget installer for POSIX shells.
   - Offline installer `install-team.sh` and bundling script `export-team.sh`.
   - Automatic Python 3 and pip dependency provisioning (Debian/Ubuntu `apt`, Fedora/RHEL `dnf`, Arch `pacman`, macOS `brew`).
   - Auto-detection and seamless configuration of `~/.gemini/antigravity/config.json`.

2. **In-Situ Vector SVG Visual Overhaul**:
   - Hand-crafted, responsive vector diagrams embedded directly into repository documentation:
     - `hero-banner.svg`: Futuristic dark-mode chassis telemetry banner.
     - `architecture-dispatch.svg`: High-velocity Auto-Dispatch topology.
     - `speculative-pipelining.svg`: Concurrent execution timeline vs sequential bottleneck.
     - `multi-dev-loop.svg`: TDD consensus & QA gate verification loop.
     - `token-shield.svg`: "Think in Code" token budget reduction benchmark.
     - `cross-platform-matrix.svg`: Full Linux vs Windows functional parity grid.

3. **Autonomous Auto-Dispatch Engine**:
   - Zero-overhead auto-routing of tasks directly to specialist subagents:
     - `system-architect` (DAG planning, ADRs, interface contracts)
     - `coordinator` (Parallel execution & contract syncing)
     - `senior-dev` (Backend logic, TDD scripts, algorithmic compute)
     - `visual-designer` (Craft UI engineering, non-AI modern aesthetics, telemetry)
     - `code-reviewer` (Security audit, invariant validation, DOD gate)
     - `typst-reporter` (GOST 7.32 papers, CeTZ vector graphics, executive PDFs)
     - `science-compute` (COMSOL Multiphysics MPh, pyfemm, dielectric calculations)
     - `cad-specialist` (KOMPAS-3D pywin32, Blender bpy procedural modeling)
     - `researcher` (Karpathy autonomous empirical research cycle)
     - `web-surfer` (Targeted search & technical standard extraction)

4. **Active Token Shield (-98.3% Context Economy)**:
   - Karpathy's "Think in Code" paradigm: agents execute compact 5-line headless probe scripts instead of ingesting multi-megabyte log files.
   - Dense YAML/TOON serialization eliminates JSON formatting bloat.
   - Halt-at-2 circuit breaker terminates failing iterative loops automatically.

## 🇷🇺 Русскоязычное описание релиза (v2.0.0)

### 🚀 Главные нововведения версии 2.0.0

1. **Кросс-платформенная поддержка Linux и macOS Терминала**:
   - Удаленный bash-инсталлятор в одну строку через `curl` / `wget`.
   - Полный оффлайн-скрипт `install-team.sh` и упаковщик `export-team.sh`.
   - Автоматическая установка системных пакетов (`apt`, `dnf`, `pacman`, `brew`) и Python-библиотек.
   - Интеллектуальная модификация конфигурационного файла `~/.gemini/antigravity/config.json`.

2. **Векторный дизайн-комплекс (Craft In-Situ SVG)**:
   - 6 авторских SVG-диаграмм высокой четкости с адаптивной темной темой:
     - `hero-banner.svg`: Главный нео-аппаратный баннер с телеметрией.
     - `architecture-dispatch.svg`: Граф автодиспетчеризации 10 субагентов.
     - `speculative-pipelining.svg`: Спекулятивный параллельный конвейер без простоя.
     - `multi-dev-loop.svg`: Цикл парного консенсуса TDD и контроля качества.
     - `token-shield.svg`: Бенчмарк снижения расхода токенов на 98.3%.
     - `cross-platform-matrix.svg`: Матрица паритета Linux и Windows.

3. **Спекулятивный параллельный конвейер (Speculative Skeleton Pipelining)**:
   - При одновременном запросе «Код/Расчет + Отчет/UI» зависимые агенты (`typst-reporter`, `visual-designer`) не ждут завершения бэкенда.
   - Каркасы верстки и интерфейсов строятся параллельно на базе контракта данных (`results.json` / `ui_data.json`), обеспечивая мгновенную сборку без задержек.

4. **Защитный щит контекста (Active Token Shield)**:
   - Парадигма Karpathy "Think in Code": компактные скрипты-зонды анализируют логи вместо считывания гигабайтов текста в контекст.
   - Использование плотной нотации TOON вместо раздутого JSON.
   - Предохранитель «Стоп на 2» предотвращает зацикливание при ошибках.
