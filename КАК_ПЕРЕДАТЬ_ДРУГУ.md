# Инструкция: Как передать настройку Antigravity другу (без Git и репозиториев)

Это готовое решение проблемы: агенты и скилы установлены в системной папке Antigravity, а проектная папка лежит отдельно. Благодаря созданному скрипту экспорта всё упаковывается в один переносимый ZIP-архив.

---

## 🚀 Шаг 1. Собрать архив у себя (1 клик)

В терминале PowerShell в папке проекта выполните:
```powershell
powershell -ExecutionPolicy Bypass -File .\export-team.ps1
```
*(Или нажмите правой кнопкой на `export-team.ps1` $\to$ **«Выполнить с помощью PowerShell»**)*.

Скрипт автоматически:
1. Заберет всех 10 субагентов, 14 скилов и правила Auto-Dispatch.
2. Приложит файл автоматического установщика `install-team.ps1` и инструкции.
3. Соберет архив **`antigravity-team-portable.zip`** и положит его вам прямо на **Рабочий стол**!

---

## 📦 Шаг 2. Отправить архив товарищу

Отправьте полученный с Рабочего стола файл **`antigravity-team-portable.zip`** другу любым удобным способом:
- Через Telegram / VK / WhatsApp
- Через Яндекс.Диск / Google Drive / облако
- На обычной USB-флешке

---

## 💻 Шаг 3. Что нужно сделать вашему товарищу

Отправьте другу эту простую памятку (она также уже лежит внутри архива):

1. **Распаковать архив**:
   - Нажать правой кнопкой на `antigravity-team-portable.zip` $\to$ **«Извлечь всё...»** (в любую папку, например в `Загрузки` или на Рабочий стол).
2. **Запустить установщик**:
   - Открыть распакованную папку.
   - Нажать правой кнопкой на **`install-team.ps1`** $\to$ **«Выполнить с помощью PowerShell»**.
   *(Или открыть PowerShell в этой папке и выполнить: `powershell -ExecutionPolicy Bypass -File .\install-team.ps1`)*.
3. **Установщик сделает всё сам**:
   - Скопирует плагин со всеми 10 агентами и 14 скилами в системную папку Antigravity (`~/.gemini/config/plugins/antigravity-team`).
   - Автоматически пропишет включение плагина в системном файле `config.json`.
   - Включит жесткий протокол автоматического выбора агентов (Auto-Dispatch).
   - Проверит Python и при согласии установит нужные инженерные библиотеки (`MPh` для COMSOL, `pytest`, `pint`, `uncertainties`, `numpy`, `scipy`).
4. **Перезапустить Google Antigravity**:
   - После перезапуска у товарища будут автоматически подключаться профильные агенты без ручного выбора!

## 🛠 Состав передаваемой команды (v2.5):

- **10 субагентов**:
  - `coordinator` (Главный архитектор и планировщик)
  - `senior-dev` (Разработчик: чистый код, TDD, фикс багов)
  - `code-reviewer` (Противнический 6-точечный QA-аудит)
  - `researcher` (Эмпирические исследования по методологии Karpathy & Hermes)
  - `system-architect` (Системная модульная архитектура и ADR по стандарту ECC)
  - `science-compute` (COMSOL Multiphysics MPh, FEMM, ГОСТ 8.207)
  - `cad-specialist` (КОМПАС-3D API 5/7, Blender bpy, 3D-печать)
  - `typst-reporter` (Отчеты ГОСТ 7.32, CeTZ)
  - `visual-designer` (Mermaid-диаграммы, Generative UI дашборды)
  - `web-surfer` (Поиск нормативов ГОСТ/IEC и актуальных доков)
- **14 специализированных навыков (Skills)**
- **Правило Auto-Dispatch**: оркестратор сам определяет задачу и вызывает нужного агента
- **Токен-экономика "Think in Code"** (экономия до 98% токенов за счет запуска headless-скриптов)
